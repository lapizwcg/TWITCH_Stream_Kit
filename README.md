# Stream Kit

Инструменты стримера на своём движке **WCG Engine** (`../WCGEngine`, подключается проектом по пути): оверлеи для OBS — оповещения,
цель трансляции, оформление.

- **Док-панель** (`dock.html`) — меню настроек: вкладки по разделам (Фолловеры, Цели…), тестовые показы. Обычная HTML-страница —
  в доке нужны поля и кнопки.
- **Показы** — источники-браузеры OBS (`index.html`): веб-сборка движка (.NET WebAssembly + WebGL2) с прозрачным холстом.
- Связь без сервера: док и источники — один браузер OBS с одним адресом; настройки — в localStorage, изменения и тесты — по
  BroadcastChannel (`kit.js`). В C# их передаёт мост страницы (`hosts/Web/Bridge.cs`).

Сейчас (без подключения к Twitch):
- **оповещение о фолловере** — карточка «заголовок · ник» со вспышками частиц (`data/fx.json`), очередь, место, время;
- **цель** — плашка с полосой прогресса и счётом, счёт ведётся вручную из дока; прибавка — искры, цель достигнута — вспышки вдоль
  полосы и «ЦЕЛЬ ДОСТИГНУТА!».

Все показы — в одном источнике на весь экран (`Stage`): один запуск движка на всё, каждый показ — в своём месте из девяти.

| Папка | Что |
|---|---|
| `src/Kit` | `Boot` — запуск (данные, материалы, эффекты, прозрачный фон); `Stage` — сцена показа; `Alerts` — оповещения; `Goal` — цель; `Layout` — девять мест и цвета материалов |
| `hosts/Web` | хост браузера: `index.html` — показ, `dock.html`/`dock.js`/`dock.css` — док-панель, `kit.js` — настройки и связь, `Bridge.cs` — мост в C# |
| `hosts/Desktop` | хост ПК — проверка и снимки |
| `data` | материалы движка, шрифт (Noto Sans, OFL), пресеты частиц |

## Twitch

Вход — в доке кнопкой «Войти через Twitch» (OAuth без сервера, `hosts/Web/wwwroot/twitch.js`). Док держит связь с
событиями канала (EventSub): новый фолловер → оповещение в показ; цель «Фолловеры канала» / «Сабы канала» считается сама (число —
с Twitch при входе и раз в две минуты, новые — сразу).

Своё приложение Twitch (Client ID — `CLIENT_ID` в `twitch.js`): https://dev.twitch.tv/console/apps → «Управление» →
«URL-адреса перенаправления OAuth» должен быть адрес дока — побуквенно, например `http://localhost:5600/dock.html`.

## Сборка и проверка

- `dotnet publish hosts/Web -c Release -o pub/web`, затем `py tools/serve.py` — раздаёт `pub/web/wwwroot` на порту 5600 без кэша
  (браузер OBS иначе держит старую версию после пересборки).
- В OBS:
  - док: Док-панели → Пользовательские док-панели браузера → `http://localhost:5600/dock.html`;
  - показ: Источники → + → Браузер → `http://localhost:5600/`, 1920×1080 — на весь экран, место карточки выбирается в доке
    (вспышки разлетаются за карточку и не обрезаются краем источника).
- Ключи адреса показа: `?pos=tr` — место только для этого источника (важнее дока), `?demo` — оповещение само раз в 6 с.
- Снимок на ПК: `hosts/Desktop/bin/Release/net10.0/KitDesktop.exe --shot=shots/alert.png --frames=40 [--pos=tr] [--goal=63/100]`.
