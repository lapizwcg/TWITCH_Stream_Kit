# Stream Kit

Инструменты стримера на своём движке **WCG Engine** (`../WCGEngine`, подключается проектом по пути): оверлеи для OBS — оповещения,
цель трансляции, оформление.

- **Док-панель** (`dock.html`) — меню настроек: вкладки по разделам (Фолловеры, Цели…), тестовые показы. Обычная HTML-страница —
  в доке нужны поля и кнопки.
- **Показы** — источники-браузеры OBS (`index.html`): веб-сборка движка (.NET WebAssembly + WebGL2) с прозрачным холстом.
- Связь без сервера: док и источники — один браузер OBS с одним адресом; настройки — в localStorage, изменения и тесты — по
  BroadcastChannel (`kit.js`). В C# их передаёт мост страницы (`hosts/Web/Bridge.cs`).

Сейчас:
- **оповещение о фолловере** — карточка «заголовок · ник» со вспышками частиц (`data/fx.json`), очередь, место, время;
- **анонсы** — свои сообщения по таймеру (раз в N минут, по очереди) и кнопкой «Показать сейчас»: в оверлей карточкой с
  переносом по словам, в чат от имени канала или туда и туда;
- у всех показов — отступ от края экрана, размер по X и по Y (текст масштабируется по меньшему, лишнее место — поля) и внутренний
  отступ (по умолчанию 1% высоты кадра);
- **цель** — плашка со счётом и прогрессом пяти видов: полоса слева направо / справа налево, столбик сверху вниз / снизу вверх,
  кольцо; счёт — «1/25». Перелив с бликом, свечение у края заливки, мягкий блеск; прибавка — искры, цель достигнута — вспышки и «ЦЕЛЬ
  ДОСТИГНУТА!». Счёт — с Twitch (фолловеры, сабы) или вручную; «Тест: 75%» в доке — заливка на 75% на несколько секунд.

Все показы — в одном источнике на весь экран (`Stage`): один запуск движка на всё, каждый показ — в своём месте из девяти.

| Папка | Что |
|---|---|
| `src/Kit` | `Boot` — запуск (данные, материалы, эффекты, прозрачный фон); `Stage` — сцена показа; `Alerts` — оповещения; `Goal` — цель; `Layout` — девять мест и цвета материалов |
| `hosts/Web` | хост браузера: `index.html` — показ, `dock.html`/`dock.js`/`dock.css` — док-панель, `kit.js` — настройки и связь, `Bridge.cs` — мост в C# |
| `hosts/Desktop` | хост ПК — проверка и снимки |
| `data` | материалы движка, шрифт (Noto Sans, OFL), пресеты частиц |

## Установка в OBS

Сайт — на GitHub Pages, ничего запускать не нужно:

| Что | Адрес |
|---|---|
| Док-панель (настройки) | https://lapizwcg.github.io/TWITCH_Stream_Kit/dock.html |
| Показ (оповещения и цель) | https://lapizwcg.github.io/TWITCH_Stream_Kit/ |

1. **Док:** Док-панели → Пользовательские док-панели браузера → имя «Stream Kit», адрес дока → «Применить». Панель можно
   пристыковать куда удобно.
2. **Показ:** в нужной сцене Источники → + → Браузер → адрес показа, ширина 1920, высота 1080 (на весь экран; место каждого показа
   выбирается в доке). Галочки «Выключать источник, когда он не виден» и «Обновить браузер, когда сцена становится активной» —
   снять.
3. В доке — «Войти через Twitch»: Twitch спросит доступ к фолловерам и сабам. Вверху появится ник и «события канала подключены».
4. Вкладка «Фолловеры»: место, заголовок, время, кнопка «Показать» — проверка. Вкладка «Цели»: что считаем, цель, место.

Док и показ должны быть открыты с одного адреса (оба с github.io) — так они видят общие настройки. Обновления приходят сами:
страницы сверяют версию при открытии и перезагружаются на новую.

## Twitch

Вход — в доке кнопкой «Войти через Twitch» (OAuth без сервера, `hosts/Web/wwwroot/twitch.js`). Док держит связь с
событиями канала (EventSub): новый фолловер → оповещение в показ; анонсы в чат — от имени канала (право user:write:chat); цель «Фолловеры канала» / «Сабы канала» считается сама (число —
с Twitch при входе и раз в две минуты, новые — сразу).

Своё приложение Twitch (Client ID — `CLIENT_ID` в `twitch.js`): https://dev.twitch.tv/console/apps → «Управление» →
«URL-адреса перенаправления OAuth» — адреса дока побуквенно: `https://lapizwcg.github.io/TWITCH_Stream_Kit/dock.html` и для
разработки `http://localhost:5600/dock.html`.

## Выкладка

`py tools/deploy.py` — собирает веб-версию здесь и отправляет готовые файлы в ветку `gh-pages` (движок `../WCGEngine` — закрытый
репозиторий, на GitHub его не собрать). В страницы вписывается номер версии — открытые в OBS страницы обновятся сами.

## Разработка

- `dotnet publish hosts/Web -c Release -o pub/web`, затем `py tools/serve.py` — раздаёт `pub/web/wwwroot` на порту 5600 без кэша
  (браузер OBS иначе держит старую версию после пересборки).
- В OBS:
  - док: Док-панели → Пользовательские док-панели браузера → `http://localhost:5600/dock.html`;
  - показ: Источники → + → Браузер → `http://localhost:5600/`, 1920×1080 — на весь экран, место карточки выбирается в доке
    (вспышки разлетаются за карточку и не обрезаются краем источника).
- Ключи адреса показа: `?pos=tr` — место только для этого источника (важнее дока), `?demo` — оповещение само раз в 6 с.
- Снимок на ПК: `hosts/Desktop/bin/Release/net10.0/KitDesktop.exe --shot=shots/alert.png --frames=40 [--pos=tr] [--goal=63/100]`.
